# 📝 Historial de versiones - EasyChat

Este documento lleva el registro de cambios significativos realizados en el proyecto **EasyChat**, siguiendo el esquema de versionado semántico.

---

## 📌 v1.0.0 - 22 de marzo de 2025

Versión inicial estable del proyecto.

### ✅ Funcionalidades incluidas:
- Registro de usuarios con correo electrónico y Firebase Authentication
- Inicio de sesión funcional
- Chat uno a uno entre usuarios
- Envío y visualización de imágenes en el chat
- Conexión con Firebase Firestore y Storage
- Estructura organizada del proyecto con POO y paquetes separados
- Pantalla de inicio y login con diseño personalizado
